# Branding assets

Upload the following image assets into this folder:

- `app-icon.png` — square PNG/JPG, preferably 1024 × 1024 px.
- `app-icon-foreground.png` — optional transparent foreground mark, 1024 × 1024 px.
- `app-icon-background.png` — optional square background image, 1024 × 1024 px. If using a solid colour, include its HEX value in your message.
- `splash-screen.png` — optional complete splash artwork, preferably 1080 × 1920 px. Alternatively upload the logo and specify the background colour separately.
- `logo-horizontal.png` or `.svg` — optional horizontal logo for login and web admin headers.
- `logo-light.png` / `logo-dark.png` — optional variants for different backgrounds.

Keep original files; do not crop or resize before upload unless requested.
