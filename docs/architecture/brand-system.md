## UI direction

- Operational, clean and legible; prioritize information density without crowding.
- Use Plus Jakarta Sans or the platform sans-serif for interface text.
- Use consistent line icons; avoid emoji as interface icons.
- Use coral sparingly for primary actions and important states.
- Prefer solid surfaces, subtle borders and restrained elevation; no decorative gradients.
- Provide clear status labels, keyboard navigation on web, accessible contrast and large touch targets on Android.
- Use responsive tables on desktop and stacked cards/action sheets on narrow screens.

## Asset handling

Before copying any logo or image, verify that it is an actual source asset and that it is suitable for use inside this business ERP. Avoid copying remote sample furniture photography, website-only decorative patterns, social preview mockups or unrelated customer imagery. Keep original attribution and licensing notes where applicable.

## Status colors

Use semantic status tokens consistently: neutral for draft, blue for in progress, amber for awaiting approval, green for completed/approved, and red for blocked/rejected/overdue. Color must never be the only status indicator.
